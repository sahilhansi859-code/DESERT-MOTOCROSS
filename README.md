## 🎮 About the Game

**Desert Motocross** is an action-packed motocross bike game set in a challenging desert environment.

The player controls a powerful motocross bike and rides through rough desert terrain, jumps over ramps and obstacles, performs stunts, and tries to complete challenging tracks.

The game is designed to provide an exciting and fun off-road motocross experience.

## 🎯 Gameplay

The main objective of **Desert Motocross** is to control the motocross bike and successfully navigate through the desert terrain.

Players need to:

1. Control the bike properly.
2. Ride through challenging terrain.
3. Avoid obstacles.
4. Jump over ramps.
5. Perform stunts.
6. Maintain balance while riding.
7. Complete the track.
8. Achieve the best possible score.
